#olist-ecommerce-mysql-eda

This project explores the Olist Brazilian e-commerce dataset through exploratory data analysis with a few simple visualizations.Most of the analysis is done in MySQL, using SQL queries to look at sales results, customer behavior, and delivery performance. Python is only used to visualize the results after the data is pulled from the database.

Tools used: MySQL, Python

The main goal of this project is to practice and improve my MySQL skills. Feel free to use this EDA for learning, reference, or any other purpose.

The final and complete analysis is presented in the olist_EDA.ipynb file. The data_import.py script can be used to create tables and import data into a MySQL database.
